Pick one. All end the same way: your agents' work, live and private, with a question before anything
risky.

<ul class="docs-tiles">
<li><a href="/docs/get-started/mac"><strong>Relo for Mac (easiest)</strong>For one Mac. Download the app, choose Run Relo on this Mac, and your agents' work shows in the notch in a few minutes. Nothing leaves the Mac: no server to run. Next: Get Relo on your Mac.</a></li>
<li><a href="/docs/get-started/windows"><strong>Relo for Windows (easiest)</strong>For one Windows PC. Download the app, choose Run Relo on this PC, and your agents' work shows in the notch in a few minutes. Nothing leaves the PC: no server to run. Next: Get Relo on your Windows PC.</a></li>
<li><a href="/docs/get-started/server"><strong>Your own server</strong>For an iPhone away from home, several computers, or Linux. You run the server, connect each computer, add your iPhone and see your first live card, in about an hour. Next: Run the server.</a></li>
</ul>

## Not sure?

Start with the Mac app if you have a Mac, or the Windows app if you have a Windows PC. It does not close any door: you can connect it to a server and
add your iPhone later. Choose your own server if you want your phone from the start, or your computers run Linux (the iPhone app is built on a Mac with Xcode).

## Your own server, step by step

Each step ends with a check you can run. If one fails, [Troubleshooting](/docs/troubleshooting) starts
from its exact output.

1. [Run the server](/docs/get-started/server): Docker Compose, your address and the owner account.
2. [Connect this computer](/docs/get-started/cli): one line in a terminal installs and signs in.
3. [Add your iPhone](/docs/get-started/iphone): build the app, add your server, allow notifications.
4. [See your first card](/docs/get-started/first-card): a test card, then a real one.
5. [Tell your agents](/docs/get-started/agents): restart them and give them one sentence.

Want your agent to walk these steps with you? Use [Set up with your agent](/docs/get-started/with-an-agent)
once the server runs, or [Start from nothing with your agent](/docs/get-started/from-scratch) to have it
run the server too. It is the same path, done for you.

To add another computer later, open **Connect a computer**: see [Connect a computer](/docs/guides/servers).
